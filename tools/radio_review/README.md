# 无线实验离线回放

把已保存的热点或 CSI 文件变成一个可直接打开的报告。用途是找出信号变化、收样断点、人工动作标签和主机自身运动，决定下一轮要测什么。

## 准备

- Python 3.10 或更高版本，仅使用标准库。
- 一份已结束采集的原始文件：N1 热点 `.json`，或 R1 CSI `.jsonl`。
- 本工具与 `components/app_csi_probe/host/analyze_capture.py` 放在同一应用目录。

这里的 **CSI** 是 Wi-Fi 信道状态信息；**RSSI** 是接收信号强度。报告中的 CSI 曲线先展示 RSSI 与帧间隔，原始载荷留在采集文件中。

## 三步使用

在本应用目录打开 PowerShell：

```powershell
python .\tools\radio_review\review.py "D:\采集\hotspot.json" "D:\采集\csi.jsonl" --out "D:\采集\review-01"
```

1. 将命令中的路径改为实际采集文件。只有一份文件时，保留一个输入路径即可。
2. 输出目录使用一个新名字，其上一级目录须已存在。看到 `Created ...report.html` 表示生成完成。
3. 双击新目录中的 `report.html`，在浏览器查看。`review.json` 保存同一份分析结果，方便后续处理。

工具只读取输入文件，报告内嵌数据、样式与脚本，可以离线打开。已有输出目录会保留，请为下一次分析换一个新目录名。

## 怎样看报告

| 位置 | 怎么操作 | 能看出什么 |
| --- | --- | --- |
| 顶部文件标签 | 点击切换；键盘左右键切换 | 分别查看各次采集 |
| 四张数字卡 | 查看记录数、时长和丢样 | 文件包含多少数据 |
| 时间曲线 | 选动作标签、拖动滑块或移动指针 | 信号变化对应了什么动作 |
| CSI 指标选择 | 切换信号与收样间隔 | 哪些位置出现收样中断 |
| 动作区间表 | 对照标签、条数和持续时间 | 一次走动或晃动覆盖的实际记录 |
| 来源与参数 | 点击展开 | 文件 SHA-256、采集身份与分析依据 |

浅绿区间表示读数有效或姿态合格；粉色表示无效读数、自身运动或姿态未知。每份文件单独从第一条记录计时。

## 输入与分析约定

- 一次接收 1–16 份文件，每份最多 64 MiB。同一种记录的采集身份须不同。
- N1 接收 `airboat.hotspot-probe.v1`，最多 1,200 条。核对连续记录编号、环形缓存覆盖、漏读计数、来源和时间回绕。距离采用人工标记。
- N1 回放配置固定为历史提交 `9f81a8c`：500 ms 读间隔、8 点窗口、首尾各 3 点中位数、6 dB 趋势门槛、2 dB 稳定门槛、3 次确认，超过 1,000 ms 断开窗口。其他参数仍可查看，回放显示“待适配”。
- 回放使用导出的观测。已覆盖的历史和未导出的重复旧读数不在文件中；回放差异需要结合原始时序核对。“首次出现对应趋势”用于对照人工标签。
- R1 接收 `airboat.csi.session.v1`、有序 `airboat.csi.raw.v1` 和结尾 `airboat.csi.end.v1`。校验沿用组件分析器；数据变动、文件截断、计数不符会终止生成。
- CSI 曲线等步长抽取，最多 6,001 点并保留末帧；计数和动作分段使用全部原始帧。图表适合看整体变化，详细复核使用原始文件。
- 区间在下一个同源采样点结束；来源或运动轮次变化、超过 1 秒的 CSI 间隔会分段，末帧不补造时长。页面表格显示前 120 段，完整分段保存在 `review.json`。
- `simulated=true` 始终显示为“模拟样例”。真实 CSI 载波格式、活动检测效果和语音／相机共存由后续采集验证。

## 电脑验证

电脑端验证由仓库统一入口执行：

```powershell
python .\tools\test.py
python .\tools\test.py --zig "C:\tools\zig\zig.exe"
```

第一条使用仓库内模拟样例运行 Python 校验；第二条额外构建真实 C 记录器并生成新模拟数据，再进行同样校验。编译器与缓存仅放在本地 `.build/`，可使用已有 Zig。具体说明见 [电脑验证](../../docs/TESTING.md)。

固件中的采样生命周期、鉴权导出和实机测试由集成方按自己的当前版本安排。
